# Projeto Cordel — Curso em Vídeo

Projeto desenvolvido durante o **Capítulo 20 do Módulo 3 do curso de HTML5 e CSS3** do canal **Curso em Vídeo**, ministrado pelo professor **Gustavo Guanabara**.

## 📜 Sobre o projeto

O projeto consiste na criação de uma página web inspirada no estilo dos **cordéis brasileiros**, utilizando poemas de **Milton Duarte** como conteúdo.

O principal objetivo do projeto é aplicar conceitos de HTML5 e CSS3 para criar uma página com diferentes efeitos visuais e uma apresentação diferenciada do conteúdo.

## 💻 Tecnologias utilizadas

* **HTML5**
* **CSS3**

## 📚 Conceitos praticados

Durante o desenvolvimento do projeto, foram praticados conceitos como:

* Estrutura semântica do HTML5
* Organização de conteúdo
* Inserção de imagens
* Links
* Formatação de textos
* Utilização de fontes personalizadas
* `@font-face`
* Imagens de fundo
* `background-image`
* `background-attachment`
* Efeito **parallax**
* Transparência
* Estilização com CSS3
* Posicionamento de elementos
* Responsividade

## 🎯 Objetivo

O objetivo deste projeto foi colocar em prática os conhecimentos de **HTML5 e CSS3**, especialmente os recursos relacionados a imagens de fundo, fontes e efeitos de **parallax**, criando uma página inspirada na literatura de cordel.
